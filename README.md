# GitHub Pages Bioinformatics Platform

This repository contains the **public-facing website** for the Bioinformatics Analysis Platform.

The actual source code is maintained in the [private repository](https://github.com/santur90/bioinfor-backup).

## Usage

1. Visit this site to access the analysis platform.
2. Upload your Count Matrix or Beta Values (CSV/TSV format).
3. Perform real-time analysis in your browser.

## Features

- 🧬 **DNAme Analysis**: Work with DNA methylation data
- 📊 **RNA-seq Analysis**: Analyze gene expression counts
- 🔒 **Privacy First**: All processing happens locally in your browser
- 📱 **Responsive**: Works on desktop and mobile devices

## Technology

- **Stlite**: Streamlit in the browser using WebAssembly
- **Python**: pandas, scipy, matplotlib, seaborn
- **GitHub Pages**: Free static hosting
